## A. Communications (backend = Agent A, panel = Agent B)
- Source of truth = what the runtime actually emitted, captured at commit boundaries (LangGraph nodes/tasks/custom events, mission delegation/ack, tool started/completed/failed, observations, safety blocks, approvals, verifier pass/fail, replans, provider (Laya/Crusoe) start/finish/error, operator lease/drive/release/deadman, navigation milestones, run end). If agents exchange no literal messages, show the true structured operational events labelled by kind (`agent_message | task_transition | tool_event | verification | safety | operator | simulation | provider`), summaries rendered from authoritative fields via deterministic templates (no extra LLM calls). `comm.operator.preview.*` is UI-only: banner 'Preview only; backend robot unchanged', never persisted as a physical action.
- Envelope `CommunicationEventV1`: event_id, run_id, seq (the existing canonical run sequence — do NOT create a second sequence), sim_tick, sim_time_ms, wall_time_utc, sender{kind,id,class}, recipient?, thread_id, task_id, mission_id, incident_id, asset_id, robot_id, message_type, phase, status, summary (bounded), evidence_ids, model_provider/model_id?, visibility, schema_version. Validate lengths/chars/FKs; redact at the write boundary. Adapt to the real schema/id types: prefer a typed projection over canonical `world_events` or write `agent_communications` + outbox in ONE transaction with linked ids; idempotent migration (next number after 0004), indexes (run_id,seq desc), (run_id,sim_tick,seq), (run_id,thread_id,seq desc).
- Delivery: publish after commit via durable outbox/stream relay on the EXISTING stream (`comm.*` events, same run_id/since_seq/gap-resync), never on the physics tick path; clients dedupe by (run_id,seq); coalesce navigation progress to milestones (never per-pose spam); safety/verification/failure events are never dropped. REST: `GET /runs/{id}/communications?after_seq&before_seq&limit&kind&agent_class&thread_id`, `GET .../communications/{event_id}`; bounded pagination; per-run authorization; no raw prompts/CoT/secrets.
- Replay: only events with sim_tick ≤ cursor (no future leakage), no LLM calls; fork = new run lineage referencing the parent checkpoint, parent immutable. Provider outage shows `Provider unavailable`, never a fake answer. A tool `completed` ≠ verified recovery (separate verification event).
- Panel UX: header (Communications, LIVE/REPLAY, connection state CONNECTING|LIVE|RECONNECTING|REPLAY|STALE|OFFLINE|ERROR, unread count, filters All/SENTINEL/INPIPE/OUTRIG/Tools/Failures/Operator + thread/robot search, X). Row: sim MM:SS (wall UTC on hover), sender class+instance, recipient, kind, summary, stage, evidence link; click → detail (trace ids, tool/model metadata, compact JSON), jump to Map robot/asset or Agents node preserving run_id + playback cursor; Jump-to-live; no forced scroll while reading history. Open/close never stops ingestion/backend, keeps filters/scroll/run context; persistent launcher with count; focus restore, ESC closes; virtualised/paginated list (100–200 rows in DOM, 5,000 events browsable); role="log", throttled aria-live polite, rare role="alert" for safety; reduced-motion; empty states 'No messages yet / Agents idle / Waiting for backend'. Default: open on desktop if space, collapsed on phones.
