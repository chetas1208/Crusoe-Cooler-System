## Decisions fixed by the lead
- **Python backend is canonical.** The TS embedded simulator (`packages/core/src/engine`, mock-api) stays on the small facility, labelled MOCK, and only needs to keep compiling/passing. Do not expand it.
- Frontend scene must be **data-driven from `/topology`** (no hardcoded hall geometry); mock keeps working because its topology is just smaller.
- ID scheme changes in the Python backend: INPIPE `IR-01..10`, OUTRIG `OR-01..06`, SENTINEL `SEN-01..05`. Old ids `c_01/c_02/o_01` appear in ~12 files (grep) — migrate them, keep tests green, no aliases in new data. The TS mock keeps old ids; the web UI must tolerate both (use ids from data, never parse them).
- Server GPUs (2× RTX 3090) are NOT used for rendering or physics unless a measured, implemented path exists. Default boundary: browser GPU renders, CPU backend simulates.
