# Provenance

This public repository is a **clean export** of a private development repository. This tree was produced by a scripted export of the private repository's commit
`c67e0e3` (committed 2026-10-17), and the public history starts fresh. The private repository keeps the full development history
(including every intermediate state); a bundle of it is retained by the maintainer.

* Pre-existing / earlier work: the simulator, mock API, web console and iOS app that predate the work listed in `PROGRESS.md` sections dated
  17 October 2026 and later (V6 layout and later). `PROGRESS.md` and `DECISIONS.md` record what was added when.
* Third-party code: see `THIRD_PARTY_NOTICES.md` and `docs/engineering/upstreams.md` (pinned revisions and licenses). No third-party source is vendored
  into this tree; CompOpt (MIT), pandapipes (BSD-3), MuJoCo (Apache-2.0), LangGraph (MIT) and others are installed as dependencies.
* Internal specification prompts, deployment identifiers, credentials and agent tooling are not part of this export.

If you need to attribute a particular file to a particular period, ask the maintainer for the private history.
